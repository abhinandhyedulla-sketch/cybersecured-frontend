Classmate Integration Guide & Code Generator
Zero-Friction SDK

Classmates can connect their Spring Boot, Python, Node.js, or React applications to this security platform by sending a single HTTP POST request whenever an event occurs (e.g. failed login, admin access, password change).

1. API Endpoint
POST http://localhost:8080/api/security/events
2. Header Authentication
X-API-Key: SEC-APP-QUIZ778899AA
3. Sample Request Body (JSON)
{
  "eventType": "FAILED_LOGIN",
  "username": "student_alex",
  "ipAddress": "192.168.1.15",
  "endpoint": "/api/quiz/auth",
  "description": "Invalid credentials provided for student_alex"
}

    "eventType": "FAILED_LOGIN",

    "X-API-Key": "SEC-APP-YOUR-KEY-HERE",
    "Content-Type": "application/json"

fetch("http://localhost:8080/api/security/events", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "SEC-APP-YOUR-KEY-HERE"
  },

    ipAddress: "192.168.1.50",

  })
})
.then(res => res.json())
.then(data => console.log("Event ingested:", data));
